# Enhancer

Резкость, чистка и цвет для видео за один проход. Есть два способа использовать, и у обоих одна и та же цепочка фильтров, так что результат совпадает:

- **Браузерная версия** (`index.html`): работает целиком на твоём устройстве, ничего не загружается.
- **Python CLI** (`enhancer.py`): тонкая обёртка над ffmpeg. Быстрее, тянет большие файлы и умеет обрабатывать несколько роликов подряд.

[English version](README.md)

## Что умеет

| Группа | Настройки |
| --- | --- |
| Размер и плавность | Апскейл до 1080p, 1440p или 2160p (Lanczos, вниз не уменьшает); смена частоты кадров на 24, 30, 48 или 60 с интерполяцией смешиванием или по движению |
| Чистка | Шумоподавление, резкость, антимерцание, удаление бандинга |
| Цвет | Контраст, яркость, насыщенность, живость, теплота |
| Вид | Плёночное зерно |
| Результат | Качество H.264 (CRF) и скорость кодирования; H.265 в CLI |

Пресеты: **Нейтральный**, **Чистка ИИ** (для мягких, чуть «пластиковых» роликов из нейросетей), **Кино**, **Чёткий** и **Плавный**.

Это классические фильтры ffmpeg (`hqdn3d`, `unsharp`, `eq`, `minterpolate` и другие). Они подтягивают и приводят ролик в порядок, но не дорисовывают новые детали, как нейросетевой апскейлер.

## Браузерная версия

Открой `index.html` (или сайт на GitHub Pages), выбери видео, возьми пресет или подвигай ползунки и нажми **Улучшить**.

- В живом превью видны цвет, резкость и зерно. Кнопка **Удерживай для сравнения** показывает оригинал.
- Шумоподавление, апскейл и частота кадров применяются при экспорте.
- Видеодвижок (ffmpeg.wasm) скачивается с CDN при первом нажатии на **Улучшить**, поэтому один раз нужен интернет.
- Браузерный движок однопоточный. Держи ролики короткими (до примерно 300 МБ), а интерполяцию по движению и 4K оставь для CLI.

## Python CLI

Нужны: Python 3.9 или новее, а также `ffmpeg` и `ffprobe` в `PATH`. Устанавливать Python-пакеты не нужно.

```
python enhancer.py in.mp4
python enhancer.py a.mp4 b.mp4
python enhancer.py in.mp4 --dry-run
python enhancer.py in.mp4 --fps 60
python enhancer.py in.mp4 --height 1080
python enhancer.py in.mp4 --codec h265
python enhancer.py in.mp4 --preset crisp
```

Результат сохраняется рядом с оригиналом как `<имя>_enhanced.mp4`, а при одном входном файле можно указать путь через `-o`. Параметры, которые ты задаёшь, перекрывают пресет.

| Параметр | Диапазон | Примечание |
| --- | --- | --- |
| `--preset` | neutral, ai-clean, cinematic, crisp, smooth | `--list-presets` покажет значения |
| `--height` / `--scale` | например 1080 / 2 | Только увеличивает |
| `--fps` | например 60 | |
| `--interp` | blend, motion | motion медленнее, но плавнее |
| `--denoise` | от 0 до 10 | |
| `--sharpen` | от 0 до 2 | |
| `--deflicker`, `--deband` | вкл. или выкл. | `--no-deflicker` отключает значение из пресета |
| `--contrast`, `--brightness`, `--saturation`, `--vibrance`, `--warmth` | от -100 до 100 | |
| `--grain` | от 0 до 40 | |
| `--crf` | от 14 до 28 | меньше = лучше качество |
| `--codec` | h264, h265 | |
| `--x264-preset` | от ultrafast до veryslow | по умолчанию `medium` |
| `--dry-run` | | печатает команду ffmpeg и останавливается |

Звук копируется без изменений, если это AAC, MP3 или ALAC. Всё остальное перекодируется в AAC на 320 кбит/с.

## Советы

- Для роликов прямо из генератора видео начни с **Чистка ИИ**, потом подправь резкость и зерно на глаз. Немного зерна прячет «пластиковость».
- Шум убирай до резкости, в таком порядке цепочка и работает. Если выкрутить оба сильно, получится замыливание.
- Интерполяция кадров может искажать быстрое движение и мелкие узоры. Проверяй результат перед использованием.
